The hidden feature

First, a feature ChatGPT never told you about.

Right-click any message in ChatGPT and you'll find "Branch in new chat" — a native feature that forks the conversation into a new thread from that point.

It's genuinely useful. It's also genuinely hidden — you have to know it exists to find it. Which is why almost no one uses it.

Why bother

Three reasons you'll use it every day.

Explore without polluting

Try a different phrasing, a wild tangent, a follow-up experiment — without ever cluttering the chat you care about.

Compare side by side

See two branches next to each other — instead of scrolling back and forth to remember what the other version said.

Keep long threads organized

Fork off sub-topics before they drown out the main conversation. Come back to them when you want.

Install

Five steps. About ninety seconds.

Not on the Chrome Web Store yet, so installation goes through Developer mode. Works on any Chromium browser — Chrome, Edge, Brave, Arc, Vivaldi.

Unzip it into a folder.

Chrome can't load a zip directly — it needs the extracted folder. Right-click the file, hit Extract All, and remember where branchit/ lands.

On Windows the built-in "Extract All" is fine. On Mac, double-clicking the zip does it automatically.

Turn on Developer mode.

Paste chrome://extensions into the address bar. Top-right corner: toggle Developer mode. New buttons appear along the top.

Same URL works on Edge, Brave, Arc — anything Chromium.

You're in.
